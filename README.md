# KAVRY COIN — Telegram Mini App v1.2

Энергия на старте 3500, аккумулятор повышает лимит на 100 за уровень. Старые аккаунты получают +3000 к энергии один раз. Сохранены все игровые механики v1.0. Пять бустов покупаются через Telegram Stars, после подтверждения платежа попадают в инвентарь и активируются вручную. VIP действует 30 дней без автоматического продления. Цены 15/30/45/60/180 Stars; суммы USD ориентировочные и зависят от стоимости Stars. Бонусная добыча не обменивается на резерв KVC; резерв не гарантирует будущую криптовалюту. Вывод закрыт.

## Запуск
1. Создайте бота в @BotFather (/newbot).
2. Разместите файлы на Node.js 20+ хостинге с публичным HTTPS, постоянным диском и одной репликой. Команда `npm start`. Перед этим выполните `npm test`.
3. Задайте переменные окружения: BOT_TOKEN (секрет из BotFather), PUBLIC_URL (HTTPS URL без пути), DATA_FILE (например /data/kavry.json, постоянный диск), WEBHOOK_SECRET (случайная строка 32–256 символов A–Z,a–z,0–9,_,-), PAYMENT_SUPPORT_TEXT (реальные контакты и инструкция поддержки), PAYMENTS_ENABLED=1. До проверки платежей оставьте PAYMENTS_ENABLED=0. PORT задаёт хостинг. Не публикуйте токен или секрет.
4. Сервер зарегистрирует webhook Telegram при старте с PAYMENTS_ENABLED=1. /health покажет payments:true только после успешной настройки. Не используйте одновременно другой webhook или polling этого же бота. В BotFather /setmenubutton задайте URL приложения и кнопку «Играть». Откройте игру из бота.
5. Для проверки интерфейса без Telegram можно открыть index.html локально. Реальная оплата доступна только из авторизованного Mini App с настроенным сервером. Никакой бесплатной тестовой выдачи в публичном сервере.

## Платежи и выпуск
Счёт создаётся сервером, сумма и получатель проверяются при pre_checkout_query, товар выдаётся только по successful_payment. Идентификаторы платежей сохраняются вместе с игровым состоянием; повторный update не выдаёт повторный товар. /paymentsupport отвечает заданными контактами. При возврате неиспользованный буст списывается из инвентаря при наличии; если уже активирован, требуется ручное разбирательство. Возврат инициируется администратором через Telegram refundStarPayment, отдельной админ-панели нет. Перед приёмом платежей настройте поддержку, правила покупки/возврата и проверьте их в тестовой среде Telegram. Не принимайте реальные платежи до полноценной сквозной проверки, резервного копирования и проверки применимых требований. Реальный токен KVC не выпущен, дата и условия выпуска не утверждены. JSON-хранилище рассчитано на одну реплику и небольшую аудиторию; для масштабирования нужна транзакционная база данных.

Документация: https://core.telegram.org/bots/payments-stars и https://core.telegram.org/bots/webapps

## Приглашения друзей (v1.2)
В BotFather включите **Main Mini App** для этого же бота и укажите PUBLIC_URL. Одной кнопки меню недостаточно для ссылок `?startapp=ref_...`. При необходимости задайте BOT_USERNAME (username бота без @); иначе сервер получает его через getMe. Вкладка «Друзья» выдаёт личную ссылку с случайным кодом. Сервер проверяет подписанный Telegram start_param и при первом входе нового аккаунта начисляет пригласившему 5000 бонусных POINTS. Приглашённый не получает отдельной награды. Повторный вход, уже существующий аккаунт и собственная ссылка не начисляют награду. Монеты пригодны для игровой прокачки, не для обмена на резерв KVC. Защита от множества отдельных Telegram-аккаунтов не гарантируется. Счётчики и коды сохраняются вместе с балансами; при обновлении не удаляйте DATA_FILE. Перед публикацией проверьте приглашение с двух настоящих Telegram-аккаунтов.
